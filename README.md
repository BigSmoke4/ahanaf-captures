## 𓂃 The feeling

**Ahanaf’s Eye** is a personal photography portfolio built around one simple idea: photographs should feel like memories, not thumbnails in a grid.

It brings together a cinematic opening, atmospheric moving imagery, handwritten lettering, and a slow, vertical gallery of photographs. Each frame arrives gently as you scroll — creating room to pause, look closer, and let the image speak.

Inspired by the warmth of analogue photography, the imperfection of handwritten notes, and the quiet beauty of editorial design.

The design favours atmosphere over ornament: oversized lettering, generous breathing room, soft colour blooms, and photographs presented like prints in a personal archive.

## ⌘ Built with

- **HTML5** — semantic page structure and media.
- **CSS3** — responsive layouts, typography, ambient effects, transitions, and animation.
- **Vanilla JavaScript** — scroll-triggered gallery reveals and reading-progress tracking.
- **Google Fonts** — Reenie Beanie for its handwritten character.
- **Intersection Observer API** — reveals gallery frames as they enter the viewport.

No framework is required for the core experience.

## ↗ Run it locally

The project is a static website. You can open `index.html` directly, but running a local server is more reliable for video and browser behaviour.

### Option 01 — Python

```bash
python -m http.server 8000
```

Then open **http://localhost:8000** in your browser.

### Option 02 — Visual Studio Code

1. Open the project folder in VS Code.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## ♡ A small note on performance

The gallery photographs use lazy loading, and the reveal animation respects the visitor’s reduced-motion preference. The opening and gallery backgrounds use looping video, so keeping those files reasonably sized helps the experience feel smoother, especially on mobile connections.
